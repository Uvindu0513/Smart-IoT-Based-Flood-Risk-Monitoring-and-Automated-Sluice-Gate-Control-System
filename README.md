# Smart-IoT-Based-Flood-Risk-Monitoring-and-Automated-Sluice-Gate-Control-System
An ESP32-based IoT Flood Risk Monitoring and Automated Sluice Gate Control System. Monitors water level, rainfall, temperature, humidity, and pressure while predicting overflow risk. Provides real-time Blynk monitoring, GSM alerts, and automatic gate control for smart reservoir and flood management.
